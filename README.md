## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or bun

### Installation

```bash
# Clone the repository
git clone git@github.com:satyamkumar216/Newgentraders.git
cd Newgentraders

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Build the production bundle
npm run build

# Preview production build
npm run preview
```
